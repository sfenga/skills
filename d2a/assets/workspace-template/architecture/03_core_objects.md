# S3 核心对象

基于真实仓库识别最多三个核心对象。避免罗列偶发性的结构体、DTO 或文件格式，除非它们是架构关键；初稿完成后依次进行压缩修订、去术语修订和口语化简化修订。

## 核心对象

最多三个核心对象是什么？对每个对象记录：

- 身份与职责
- 谁创建、消费、持久化或驱动它
- 与其他核心对象的关系
- 代码证据与置信度
