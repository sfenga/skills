# S99 代码地图

S99 是证据门。把 S1 至 S6 的每项主要架构结论映射到真实文件与符号；所有路径必须是项目内相对路径，无法验证的结论必须明确列入“未验证问题”，不能伪造证据。

## 结论到代码映射

逐项记录：来源阶段、架构结论、真实文件、符号或行级定位、该证据证明什么，以及 `low`、`medium` 或 `high` 置信度。相同映射同时写入 `99_evidence.json`。
`99_evidence.json` 的每项必须包含 `source_stage`、`claim`、`symbol`、`proves`、`confidence` 和非空 `evidence`，并覆盖 S1 至 S6。

## 入口点

记录启动入口、外部输入入口、核心运行入口和持久化入口；说明每个入口如何进入主流程。

## 定义点、更新点与持久化点

记录核心对象与状态的定义位置、主要更新位置、持久化位置和恢复位置。

## 推荐阅读顺序

给出理解架构所需的最短阅读顺序，并说明每一步要回答的问题。

## 初次阅读可忽略部分

指出初次阅读可忽略的生成代码、适配层、界面细节或其他非核心实现，并说明原因。

## 未验证问题

列出证据不足、存在冲突或只能推断的问题，以及继续验证所需查看的位置。
